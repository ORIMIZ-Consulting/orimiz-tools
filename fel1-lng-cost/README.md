# FEL1 LNG Cost has moved

The FEL1 LNG Cost tool now lives in its own repository:

**https://github.com/ORIMIZ-Consulting/open-fel1-lng-cost**

The tool makes a first capital cost estimate for a liquefied natural gas (LNG) plant at Front-End Loading 1 (FEL 1), the concept stage.

The new repository keeps the full commit history of this folder. Please use it for new versions, issues and changes. The old files remain in the history of this repository.
