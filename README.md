# My-Tools

Free and open tools for the energy industry and investments.

Each tool sits in its own folder, with its own instructions, data and tests.

| Tool | What it does |
|---|---|
| [FEL1 LNG Cost](https://github.com/ORIMIZ-Consulting/open-fel1-lng-cost) (moved to its own repository) | FEL 1 (AACE Class 5) capital cost for LNG liquefaction plants from public analog projects, following a 13-step guideline. FLNG, regas and FSRU in preview |

## Using a tool

1. Download this repository: click the green **Code** button, then **Download ZIP**. Or, if you use git: `git clone https://github.com/ORIMIZ-Consulting/My-Tools.git`
2. Open the tool's folder and follow its README.

## A note on the numbers

These tools are for screening and learning. They use public data and published methods only. Check the sources and assumptions before you rely on any result.
